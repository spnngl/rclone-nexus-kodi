Kodi application architecture: armeabi-v7a / 32-bit ARM
Official rclone 1.75.2 executable (https://beta.rclone.org/v1.75.2/testbuilds/):

rclone-android-21-armv7a.gz

Copy it into this directory as rclone.gz, or decompress it as rclone.
Use this for 32-bit Kodi, including many Fire TV installations with ARM64 hardware.
Rclone Nexus requires rclone 1.75.2 or newer and checks the version before use.
